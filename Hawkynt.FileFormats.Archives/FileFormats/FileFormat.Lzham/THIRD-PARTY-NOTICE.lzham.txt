Converted into this directory:

  lzhamdecomp/lzham_lzdecomp.cpp, lzham_symbol_codec.h (decoding macros)
                                         -> LzhamDecoder.cs
  lzhamdecomp/lzham_symbol_codec.cpp, lzham_huffman_codes.cpp,
  lzham_prefix_coding.cpp, lzham_lzdecompbase.cpp (tables)
                                         -> LzhamModels.cs
  lzhamdecomp/lzham_symbol_codec.cpp (encoding side, g_prob_cost),
  lzhamcomp/lzham_lzcomp_state.cpp (state::encode, encode_eob, the cost
  functions, partial_advance),
  lzhamcomp/lzham_lzcomp_internal.cpp (compress_block_internal,
  optimal_parse, extreme_parse, node::add_state, send_final_block),
  lzhamcomp/lzham_lzcomp_internal.h (level settings, complexities)
                                         -> LzhamEncoder.cs
  lzhamcomp/lzham_match_accel.cpp (search_accelerator without helper
  threads)                               -> LzhamMatchAccelerator.cs

The compressor is LZHAM's single-threaded path: with the same dictionary
size, table update rate, level and extreme-parsing flag it writes the bytes
lzhamtest -t0 writes. LZHAM's helper-thread parse (several parse jobs with
partial state resets), its greedy parse for seed dictionaries and its
TRADEOFF_DECOMPRESSION_RATE_FOR_COMP_RATIO table-rate resets were not
converted.

LzhamStream.cs follows the file layout written by lzhamtest/lzhamtest.cpp
(id "LZH0", dictionary size log2, 64-bit little-endian length).
