libzpaq / zpaq 7.15 — converted to C#

Source:   http://mattmahoney.net/dc/zpaq715.zip (zpaq v7.15, Aug 17 2016)
Author:   Matt Mahoney
Licence:  public domain (The Unlicense, reproduced below) for zpaq.cpp,
          libzpaq.h and libzpaq.cpp. The libdivsufsort-lite section of
          libzpaq.cpp (MIT) was NOT taken: suffix arrays are built by
          ZpaqSuffixArray.cs, an SA-IS implementation written from the
          Nong/Zhang/Chan paper. A suffix array is unique, so the BWT and
          LZ77 output is unchanged.
Spec:     The ZPAQ Open Standard Format for Highly Compressed Data, Level 2,
          http://mattmahoney.net/dc/zpaq206.pdf

The files in this directory are a conversion into this codebase, not a
verbatim copy:

  libzpaq.cpp ZPAQL (interpreter)      -> ZpaqlMachine.cs
  libzpaq.cpp Predictor (interpreter)  -> ZpaqPredictor.cs
  libzpaq.cpp Decoder, Encoder,
              PostProcessor            -> ZpaqCoder.cs
  libzpaq.cpp Decompresser             -> ZpaqDecompresser.cs
  libzpaq.cpp Compiler                 -> ZpaqCompiler.cs
  libzpaq.cpp Compressor               -> ZpaqCompressor.cs
  libzpaq.cpp makeConfig, compressBlock,
              e8e9                     -> ZpaqMethods.cs
  libzpaq.cpp LZBuffer                 -> ZpaqLzBuffer.cs
  libzpaq.cpp StringBuffer, SHA1 use   -> ZpaqIo.cs
  zpaq.cpp Jidac::read_archive,
           extract                     -> ZpaqReader.cs
  zpaq.cpp Jidac::add                  -> ZpaqWriter.cs

Constant tables (bit-history state table, CM/MATCH divisor tables, squash
and stretch tables, the add() analysis divisor table, the locator tag, the
ZPAQL opcode list and the generated ZPAQL programs for methods 0..5) are
copied exactly, as the format requires.

Not converted: the x86/x64 JIT, AES-256 encryption and scrypt key stretching
(encrypted archives are refused), multi-part and index (-index) archives,
and appending a new version to an existing archive (the writer emits a
single-version archive; modify rebuilds it).
