mrimg-tools (Christopher Cooper) — Macrium Reflect pre-X block codec layout

Revision: e91fc3698de76e7292cec3dea90d0bbb866cc5b0 (repository head; no
          commits since 2016)
Author:   Christopher Cooper
Licence:  MIT (reproduced below)

MacriumPreXCodec.cs implements the pre-X block-payload token layout that
mrimg-tools describes in its Python proof of concept. The C# decoder is this
project's own; the attribution is kept because the layout was taken from that
project and the source comments call the codec a port of it.
