The NSIS reader and installer writer in this directory were written from these sources:

1. NSIS (Nullsoft Scriptable Install System), https://github.com/kichik/nsis, master as of
   2026-10-19: Source/exehead/fileform.h, fileform.c, util.c (installer layout, opcodes,
   string escape codes) and Source/bzip2/decompress.c (the header-less bzip2 framing: block
   marker 0x31, end marker 0x17, no CRCs). The structures and constants were taken over; the
   code here is a new C# implementation.

   The writer (NsisInstallerWriter.cs, NsisStubPatcher.cs) also follows NSIS 3.10's
   nsis-3.10-src.tar.bz2: Source/build.cpp (header block order and defaults, the .ndata size,
   the manifest and PE header values set on the stub), Source/fileform.cpp (language-table
   layout), Source/exehead/fileform.c (the CRC-32 from byte 512), and takes the English
   interface texts of Contrib/Language files/English.nlf. It ships no part of NSIS's exehead:
   the stub, which is native code and whose LZMA module is under the Common Public License 1.0,
   is supplied by the user from their own NSIS installation.

2. 7-Zip, https://github.com/ip7z/7zip, CPP/7zip/Archive/Nsis/NsisIn.cpp and NsisDecode.cpp
   (GNU LGPL 2.1 or later), Copyright (C) Igor Pavlov: the compressor-signature table, the
   NSIS 2 / NSIS 3 string-dialect check, the NSIS 2 stored-block rule (LEN without NLEN), the
   shell-folder name table and the rule for naming files relative to $INSTDIR. Adapted into
   this LGPL-3.0-or-later code base.

   Added 2026-11-03 from 7-Zip 23.01 (7z2301-src.7z, the same files plus NsisHandler.cpp):
   the WriteUninstaller item (name from parameter 0, or parameter 3 when that is
   "$INSTDIR\" + name; "*.nsis" without an exe stub), the strict reading of the icon-patch
   records, and the InstallLib naming rule (File $R0 named by the "StrCpy $R4" 28, or 26,
   instructions back).

3. NSIS 3.10 (nsis-3.10-src.tar.bz2), Source/exehead/exec.c EW_WRITEUNINSTALLER and
   Source/build.cpp: the uninstaller is the installer's exe stub (everything before
   firstheader) with the icon patch applied, followed by the data block after the patch;
   an icon-patch size of 0 means the block holds the whole uninstaller. Same zlib/libpng
   licence as item 1.

The x86 branch filter that 7-Zip's installers apply to their LZMA stream is decoded with
Compression.Core's liblzma conversion (Compression.Core/Transforms/THIRD-PARTY-NOTICE.liblzma.txt).
