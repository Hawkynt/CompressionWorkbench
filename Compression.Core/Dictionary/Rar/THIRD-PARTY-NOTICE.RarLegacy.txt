Files converted:

  XADRAR15Handle.m           -> Rar1Decoder.cs
  XADRAR20Handle.m           -> Rar2Decoder.cs
  RARAudioDecoder.c (RAR 2.0 part) -> Rar2Decoder.cs (AudioState)
  XADPrefixCode.m (canonical code construction) -> RarLegacyCoding.cs

The static RAR 1.5 code-length tables are carried across exactly, written as
(length, run) pairs. The CSHandle/LZSS framework around the decoders is not
converted; the decoders keep their own window and an MSB-first bit reader.
Checked against archives written by RAR 1.5x and 2.0x (see
Compression.Tests/Rar/LegacyVectors/README.md), whose output matches 7-Zip's.
