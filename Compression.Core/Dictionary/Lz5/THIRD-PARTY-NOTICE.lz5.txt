LZ5 1.5 — converted to C#

Source:   lz5 by Przemyslaw Skibinski, based on LZ4 by Yann Collet,
          https://github.com/inikep/lizard (the project was named lz5 up to
          1.5 and renamed Lizard from 2.0), tag v1.5, commit
          95a8be6aa9e9ffc3c5b72a468a4d4de2b3d0db65, directory lib/
Licence:  BSD 2-Clause (lib/LICENSE, reproduced below)

Conversions:

  lib/lz5.c        LZ5_decompress_generic           -> Lz5Block.Decode
  lib/lz5common.h  MINMATCH, LASTLITERALS, MFLIMIT,
                   MAXD_LOG, ML_BITS, RUN_BITS(2),
                   LZ5_SHORT/MID_OFFSET_BITS         -> Lz5Block constants
  lib/lz5frame.c   LZ5F_decodeHeader, LZ5F_getBlockSize,
                   LZ5F_headerChecksum, block and
                   content checksum handling         -> Lz5Frame

Lz5Block.Encode is this repository's own greedy encoder for the same block
format; it keeps the parsing restrictions of lib/lz5common.h (the last 5
bytes are literals, no match starts in the last 12 bytes).
