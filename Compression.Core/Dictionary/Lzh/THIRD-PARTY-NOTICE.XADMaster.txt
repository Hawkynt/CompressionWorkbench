Files converted:

  XADLZHOldHandles.m (LZHUFF2/LZHUFF3 paths) -> Lh2Decoder.cs, Lh3Decoder.cs,
                                                LhaLegacyBitReader.cs

The decoders are conversions: the adaptive two-tree bookkeeping of -lh2- and
the per-block static trees with the "ready made" position table of -lh3- are
carried across, with the tables copied exactly. One deliberate difference:
XADMaster sizes the -lh3- position alphabet as 1 << (16 - 6); the ready-made
table only satisfies Kraft's equality with 128 symbols (8 KiB / 64), so 128 is
used. Checked against lh2.lzh and lh3.lzh from the lhasa test suite (written
by UNLHA32.DLL 2.67a), whose CRC-16s the output matches.
