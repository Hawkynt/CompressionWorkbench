SquashFsLegacyReader.cs is a conversion of the parts of that handler that read SquashFS
1.x, 2.x and 3.x images: the superblock fields per major version (CHeader::Parse3), the
inode layouts and their big-endian bit-field order (CNode::Parse1/Parse2/Parse3), the
metadata-block framing with the optional check byte (ReadMetadataBlock), the directory
header and entry layouts (OpenDir), the fragment index (Open2), the block lists
(GetPackSize), the mtime offsets and the uid/gid lookup with the "same as uid" gid index
(GetProperty). The C++ structure was not kept; the reader is written against this
code base's own zlib decoder, which also checks each block's Adler-32.
