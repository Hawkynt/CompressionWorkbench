PackMp3Codec.cs, PackMp3Arithmetic.cs and PackMp3BitIO.cs convert the files
above; PackMp3Tables.cs copies the frame-size, band-bound, CRC-16,
bandwidth-conversion and bitrate-prediction tables and the ISO/IEC 11172-3
Huffman code tables exactly. ZIP method 94 (WinZip MP3) carries this stream.

Modifications: converted to C#; works on memory buffers instead of files;
malformed input raises InvalidDataException (or NotSupportedException for MP3
features packMP3 does not support) instead of reading past buffers; Huffman
decoding walks trees built from the encoding tables.
