Ppmd7.cs converts the model, the sub-allocator and the symbol decoder, plus the
carry-less range decoder RAR 3.x uses. The C version keeps its heap behind a base
pointer. Here it is a byte array addressed by offset, with the same layout, so the
model behaves bit for bit like the C one.
