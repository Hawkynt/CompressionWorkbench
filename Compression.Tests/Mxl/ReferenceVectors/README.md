# MXL reference vectors

Compressed MusicXML scores from the OpenSheetMusicDisplay test corpus (`test/data/` in
<https://github.com/opensheetmusicdisplay/opensheetmusicdisplay>, revision
`0e55fe60a26b6d0fc6f67b4aad8013580637e281`, fetched 2026-10-26), unmodified.

| File | SHA-256 |
| --- | --- |
| `OSMD_function_test_metronome_marks.mxl` | `0f25498d9a1fefd78125ccf21966dabc4680467a0bd7e6cf2eef3b8fef018507` |
| `test_mxl_with_utf-16_xml.mxl` | `9e40dff4654ddea45119861f02b908277d5754b64a11c72c063c4f5e32d8c75e` |

The expected member names, sizes and CRC-32s in `MxlTests` are 7-Zip 26.04's `7z l -slt` output for
these files.
