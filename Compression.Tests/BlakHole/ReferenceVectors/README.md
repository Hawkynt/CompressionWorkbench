# BlakHole reference vector

`test.bh` (152 768 bytes) comes unmodified from the Archive Team sample corpus at
<http://sembiance.com/fileFormatSamples/archive/blakHole/> and was downloaded on 2026-10-30. It
holds five office documents: `.doc`, `.docx`, `.odt`, `.pdf` and `.rtf`. Each member has a
CRC-32, and all five decode to data that matches it. That CRC is the evidence for the layout in
`docs/BLAKHOLE-ON-DISK.md`.
