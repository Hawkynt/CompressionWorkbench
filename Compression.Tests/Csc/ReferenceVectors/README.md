# libcsc reference streams

Every `.csc` file here was written by the reference `csc` tool of libcsc, Fu Siyuan's CSC
(<https://github.com/fusiyuan2010/CSC>, public domain), at commit
`c5dbe0944d07acbc97d2c04ec9f99a139c6f3931` (2016-10-13).

The tool was built from `src/libcsc/*.cpp` with MSVC 14.51 (x64, `/O2 /EHsc /D_7Z_TYPES_`) and run
as `csc c <switches> input output`. The input of each file is generated by `CscSamples` in this
directory's parent, so only the compressed side is checked in:

| File | Input | Switches | Blocks the stream contains |
|------|-------|----------|----------------------------|
| `empty.m2.csc` | 0 bytes | `-m2` | end of stream only |
| `one.m2.csc` | `"A"` | `-m2` | LZ |
| `text-20k.m1.csc` .. `text-20k.m5.csc` | `Text(20000)` | `-m1` .. `-m5` | English text (word filter + LZ) |
| `x86-24k.m2.csc` | `X86(24576)` | `-m2` | x86 (E8/E9 filter + LZ) |
| `table-64k.m2.csc` | `Table(65536)` | `-m2` | delta, 4 channels (delta + RLE) |
| `table-32k.m2.fdelta0.csc` | `Table(32768)` | `-m2 -fdelta0` | LZ (delta filter switched off) |
| `alphabet-16k.m2.csc` | `SmallAlphabet(16384)` | `-m2` | order-1 literals |
| `mixed.m2.csc` | `Mixed()` | `-m2` | text, stored, delta, literals, x86 in one segment |
| `text-60k.m2.d32k.csc` | `Text(60000, 5)` | `-m2 -d32k` | text; the 42 KiB window wraps |
| `text-60k.m5.d32k.csc` | `Text(60000, 5)` | `-m5 -d32k` | text; binary-tree match finder, window wraps |
| `ramp-4500k.m2.csc` | `Ramp(4500000)` | `-m2` | LZ over three 2 MiB segments |

The reference encoder leaves one byte of each segment's last range-coder block uninitialised (a
guard byte the decoder never reads), so those bytes are whatever the MSVC heap held. The tests
that compare our encoder's output with these files mask exactly those bytes; everything else
must match byte for byte.
