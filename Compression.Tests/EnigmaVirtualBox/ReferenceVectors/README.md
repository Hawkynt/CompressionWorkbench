# Enigma Virtual Box reference boxes

All five are executables Enigma Virtual Box itself boxed, stored gzip-compressed and otherwise
unchanged. None was built by CompressionWorkbench, and none was run.

| Fixture | Packer | Contents |
| --- | --- | --- |
| `x64-evb1100.exe` | EVB 11.00 (x64) | `README.txt` |
| `x86-evb970.exe` | EVB 9.70 (x86) | `README.txt` |
| `x86-evb780.exe` | EVB 7.80 (x86), the legacy table layout | `README.txt` |
| `evb-stored.exe` | EVB 11.30 (x64), files not compressed | `hello.txt`, `empty.txt`, `data/random.bin`, `data/sub/pattern.bin` |
| `evb-compressed.exe` | EVB 11.30 (x64), "Compress files" on | the same four files, aPLib-chunked |

The first three are evbunpack's test files (https://github.com/mos9527/evbunpack, Apache-2.0,
revision ee7b647acf2a46617b0c448dfa83d63132ea917b, `tests/x64_PackerTestApp_packed_20240826.exe`,
`tests/x86_PackerTestApp_packed_20210329.exe`, `tests/x86_PackerTestApp_packed_20170713.exe`); its
licence is in `../../../Hawkynt.FileFormats.Archives/FileFormats/FileFormat.EnigmaVirtualBox/THIRD-PARTY-NOTICE.evbunpack.txt`.

The last two were boxed by `enigmavbconsole.exe` of Enigma Virtual Box 11.30 (Build 20250429,
`https://enigmaprotector.com/assets/files/enigmavb.exe`, SHA-256
ab743f5e3dd927a288e126bbb053d367f270592e89378c9a06b7f3b15fa1ee35, unpacked with innoextract 1.9
rather than installed): `python make-fixtures.py <workdir> <enigmavbconsole.exe> <host exe>`,
with evbunpack's `tests/x64_PackerTestApp.exe` as the host. The payload is generated by the script.

`oracle.tsv` is what evbunpack 0.2.3 (`pip install evbunpack==0.2.3`) extracts from each box —
path, size and SHA-256 — written by `python make-oracle.py <evbunpack dir> <workdir> . <fixtures...>`
(`x86-evb780.exe:legacy` selects its legacy walker).
