# Quantum reference cabinet

`libmspack-mixed.cab` is `cabextract/test/cabs/mixed.cab` from libmspack (LGPL-2.1-or-later,
Stuart Caie) at `55d501976171397ccd5d5a7a1ca7da065b1d9a06`: three folders, MSZIP, LZX:18 and
Quantum:18, written by Microsoft's cabinet tools. 7-Zip 26.04 tests it as OK. Its Quantum folder
holds `qtm.txt` ("If you can read this, the Quantum decompressor is working!\n", 59 bytes) in one
48-byte block.
