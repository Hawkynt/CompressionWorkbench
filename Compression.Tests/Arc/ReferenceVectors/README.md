NoGate Consulting's own distribution of PAK 2.51 (October 1990), copied unaltered from the Garbo
MS-DOS archive (`http://www.retroarchive.org/cdrom/garbo_dos/arcers/pak251.exe`; the same file
is on the Simtel MS-DOS CDs, `arcers/`). It is a PAK self-extractor. The archive starts at offset
`0x1AD3`, after the extraction stub. `READ.ME` is stored with method 10 (Crushed). `PAK.EXE`,
`PAK.DOC`, `PAKINST.EXE`, `ORDER.FRM`, `UPDATE.FRM`, `SITE.FRM`, `STDCFG.TXT` and `ALTCFG.TXT` are
stored with method 11 (Distilled). CompressionWorkbench did not make this file.

Redistribution: PAK is shareware. Its documentation (`PAK.DOC`, "The Shareware Concept") lets
anyone copy and distribute it free of charge, provided it is not altered. The file is kept here
byte-identical and is never modified or packaged.
