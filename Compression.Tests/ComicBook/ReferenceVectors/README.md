# Comic book reference vectors

`ours.cba` is what `CbaFormatDescriptor.Create` (that is, the ACE writer) produced for two pages,
`page01.png` (22 bytes) and `page02.png` (5000 bytes); see `CbaTests.WriteOurs`. acefile
(droe/acefile 11ed076a, BSD-2-Clause) lists both members and tests them as `success`; its output is
in `acefile-cba-listing.txt`.
