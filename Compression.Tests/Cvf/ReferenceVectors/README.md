# CVF reference cluster payloads

Every `.bin` file here is one compressed cluster written by the compressors of **dmsdos**, the
independent Linux DoubleSpace / DriveSpace / Stacker implementation (GPL,
<https://github.com/sandsmark/dmsdos>, master branch as fetched 2026-10-19). dmsdos is used only as
a black-box oracle; none of its code is in this repository.

The library was built in its userspace mode exactly as `Support/DmsdosCache.cs` builds it (CMake,
`-D__DMSDOS_LIB__ -DUSE_FLOCK -U__linux__`, GCC on Ubuntu under WSL 2). A small driver program
linked against `libdmsdos.a` called, for each sample:

* `dbl_compress(out, in, sectors, method, 11)` for `ds00` (DS-0-0), `jm00` (JM-0-0), `jm01`
  (JM-0-1, DriveSpace 3 *High*) and `sq00` (SQ-0-0, DriveSpace 3 *Ultra*) — the output is the
  whole sectors the driver would write;
* `stac_compress(in, length, out, length, SD_3 or SD_4, 11)` for `sd3` and `sd4` — the output is
  the exact byte count it returned.

Compression factor 11 is dmsdos's default (`DEFAULT_CF`). Each payload was then decoded with
dmsdos's own `ds_dec` / `jm_dec` / `sq_dec` / `sd3_decomp` / `sd4_decomp` and compared with the input
before being checked in.

The inputs are generated by `CvfSamples` (only the compressed side is checked in):

| Sample | Bytes | Generator | Methods |
|--------|------:|-----------|---------|
| `text-8k` | 8192 | `CscSamples.Text` | ds00 jm00 jm01 sq00 sd3 sd4 |
| `x86-8k` | 8192 | `CscSamples.X86` | ds00 jm00 jm01 sq00 sd3 sd4 |
| `table-8k` | 8192 | `CscSamples.Table` | ds00 jm00 jm01 sq00 sd3 sd4 |
| `alphabet-8k` | 8192 | `CscSamples.SmallAlphabet` | ds00 jm00 jm01 sq00 sd3 sd4 |
| `dir-8k` | 8192 | `CvfSamples.Directory` | ds00 jm00 jm01 sq00 sd3 sd4 |
| `text-32k` | 32768 | `CscSamples.Text` (a DriveSpace 3 cluster) | jm00 sq00 |

The format these streams follow is written down in `docs/CVF-CODECS-ON-DISK.md`.
