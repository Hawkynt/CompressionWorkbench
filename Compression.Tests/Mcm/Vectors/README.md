# MCM reference archives

Written by **mcm 0.84** (`github.com/mathieuchartier/mcm`, master `1c44c95a`, built with MinGW-w64
g++ `-O3 -std=c++11`, Windows), run in a scratch directory as `mcm.exe <options> <input> <archive>`.
The inputs are regenerated by the tests (`McmVectors` in `McmTests.cs`, the same generators as
`CodecProof/CodecProofData`), so only the archives are stored.

| Archive | Input | Options | What it pins |
|---|---|---|---|
| `text-t0.mcm` | `text.txt` = `Text(20000)` | `-t0` | turbo CM, text model, dictionary filter |
| `text-m2.mcm` | same | `-m2` | mid CM |
| `text-h1.mcm` | same | `-h1` | high CM (10 inputs) |
| `text-s0.mcm` | same | `-s0` | the undocumented simple level |
| `text-store.mcm` | same | `-store` | stored payload behind the dictionary filter (memory level 6) |
| `mixed-f0.mcm` | `mixed.bin` = `Mixed(20000)` | `-f0` | fast CM, binary model, x86 filter, LZP |
| `random-t0.mcm` | `random.bin` = `Random(30000)` | `-t0` | the binary fast path; **mcm cannot extract this archive itself** (it restores byte 24 999 onwards wrongly) |
| `tone-f0.mcm` | `tone.wav` = stereo 16-bit triangle waves, 12 000 frames | `-f0` | the Wav16 coder; **mcm cannot extract this archive itself** (its Wav16 decoder does not invert the encoder) |
| `tree-m0.mcm` | directory `tree` (`a.txt`, `b.bin`, `empty.dat`, `sub/c.cpp`) | `-m0` | file list with directories, sort order, an empty file, two solid blocks of equal size |
