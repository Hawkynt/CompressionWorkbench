# QCOW2 reference vectors

Images written by QEMU's own tools (`qemu-img` and `qemu-io` from Ubuntu 24.04's `qemu-utils`,
QEMU 8.2, run in WSL) by `Qcow2QemuFeatureTests.Given_QemuTools_When_TheVectorsAreRegenerated_Then_TheyMatchTheCommittedOnes`
with `CWB_QCOW2_WRITE_VECTORS=1`. The 256 KiB guest disk is generated by the test itself (text-like
bytes, a zero gap, a seeded pseudo-random block).

| File | Made with | What it covers |
| --- | --- | --- |
| `zstd.qcow2` | `qemu-img convert -c -O qcow2 -o compression_type=zstd,cluster_size=4096` | zstd-compressed clusters (incompatible feature bit 3, compression type 1), and the random block stored uncompressed |
| `extl2.qcow2` | `qemu-img create -o extended_l2=on,cluster_size=16384` + `qemu-io` writes and `write -z` | extended L2 entries: allocated, zero and unallocated subclusters within one cluster |
| `base.qcow2` | `qemu-img create -o cluster_size=4096` + `qemu-io` writes | backing file of the two children below |
| `child.qcow2` | `qemu-img create -b base.qcow2 -F qcow2` + `qemu-io` | QCOW2 backing file, a zero cluster over backing data |
| `child-extl2.qcow2` | as above with `extended_l2=on,cluster_size=16384` | partial subclusters whose neighbours come from the backing file |
| `base.raw`, `child-raw.qcow2` | `qemu-img create -b base.raw -F raw` | raw backing file |

`qemu-raw.sha256` holds, for each image, the SHA-256 of `qemu-img convert -O raw <image>` — the
guest disk as QEMU reads it, backing chain included. Each image also passed `qemu-img check`. The
regeneration test rebuilds everything with QEMU and requires the same hashes (QEMU's output is
deterministic for these inputs), then reads the fresh images with our reader as well.

## Encrypted images

`mkencrypted.sh` (documentation, not a build input) made these with `qemu-img convert` from a
64 KiB guest disk (text-like bytes, a zero gap, a seeded pseudo-random block); the password is
`Secr3t`. They are stored gzipped. `qemu-encrypted.sha256` holds the SHA-256 of the raw guest disk
`qemu-img convert --image-opts ... encrypt.key-secret=...` decrypted from each.

| File | Made with | What it covers |
| --- | --- | --- |
| `enc-aes.qcow2.gz` | `-o encrypt.format=aes,cluster_size=4096` | legacy AES encryption (crypt_method 1) |
| `enc-luks-cbc-essiv.qcow2.gz` | `-o encrypt.format=luks,encrypt.cipher-alg=aes-128,encrypt.cipher-mode=cbc,encrypt.ivgen-alg=essiv,encrypt.ivgen-hash-alg=sha256,encrypt.hash-alg=sha1,encrypt.iter-time=10,cluster_size=4096` | LUKS encryption (crypt_method 2): the LUKS1 header behind the encryption header extension, AF-split key material, CBC with ESSIV over host sectors |

The default LUKS profile (aes-256 xts-plain64, sha256) and further cipher profiles are checked
live against qemu-img by `Qcow2EncryptionTests` in the ExternalInterop tier.
