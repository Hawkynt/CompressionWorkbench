SPIFFS (Peter Andersson) — on-disk layout followed from the reference implementation

SpiffsGeometry.cs, SpiffsReader.cs and SpiffsWriter.cs follow SPIFFS' page,
object lookup and object index layout: the lookup-page count, the magic and
erase-count slots, the page header and object index header structures, the
page flags and the span-index arithmetic of the index tables. The scanning,
geometry detection and image building are this project's own; no SPIFFS
function was transliterated.
