binwalk v3 (ReFirmLabs) — SEAMA / DLOB header layout converted to C#

Source:   https://github.com/ReFirmLabs/binwalk
Revision: 26713972e3f9f52dc37d4a421c4554b0bd9e82ef (checked against when this notice was written)
Licence:  MIT (reproduced below)

SeamaImage takes the SEAMA header layout from src/structures/seama.rs and dlob.rs, converted into
this codebase rather than copied. The magic and field offsets are copied exactly, as the format
requires. The meta encoding, MD5 coverage and seal structure were measured separately, from OpenWrt
firmware-utils seama / oseama run as black boxes (GPL-2.0; none of their code is in this
repository). binwalk v3 is also run as a black-box oracle in the test suite.
